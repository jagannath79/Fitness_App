# Fitness App

A simple Android fitness dashboard built with Kotlin and XML layouts. The app highlights weekly goals, hydration, workouts, nutrition, and recovery.

## Project structure
- `app/src/main/java/com/fitnessapp/MainActivity.kt`: entry activity.
- `app/src/main/res/layout/activity_main.xml`: main dashboard layout.

## Running locally
Open the project in Android Studio and run the `app` configuration on an emulator or device.
